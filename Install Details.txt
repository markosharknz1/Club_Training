For today's demo on Carol's machine, here's what you need:

**Install Python 3.12** (the version this app was built and tested on) — download from [python.org/downloads](https://python.org/downloads).

**One critical step during install:** tick **"Add python.exe to PATH"** on the first installer screen. That's the #1 thing that causes `install.bat`/`run.bat` to fail with "Python not found."

**Then on Carol's machine:**
1. Copy the `BadmintonClub` folder to a normal local location (not OneDrive/Dropbox — same corruption risk as before)
2. Run `install.bat` once (installs flask, flask-sqlalchemy, openpyxl, reportlab)
3. Run `run.bat` — opens the app in the browser automatically

Any Python 3.9+ would likely work fine too (nothing in the code uses bleeding-edge syntax), but 3.12 is the known-good version since that's what's been tested against throughout this build. If Carol's machine already has an older Python 3 on it, it's probably fine to just try `install.bat` first before bothering to install a fresh version.
