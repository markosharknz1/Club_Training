Import Sports Vouchers from CSV
← Back

Accepts .csv or .xlsx, in either of two shapes:

  • Voucher list — columns name (the child, must already exist in the Player Database), voucher_number, amount (default 100), sessions (default 10), date_issued (2026-08-01 or 01/08/2026), notes. Only name is required.
  • Carryover balance sheet — a Name column plus a "remaining lessons" number column (title rows above the header are fine; a date like 5/7/26 in the title is used as the issue date). Each row becomes a voucher with exactly that many sessions left.

Rows are checked against the normal voucher limits (max 2 active, max 2 per calendar year), already-registered voucher numbers are skipped, and unknown player names are listed so you can add them first. Don't import the same balance sheet twice — each import creates new vouchers.
