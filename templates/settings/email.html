Enables the Email page for announcements (tournaments etc.) and the provider settings below.
Every email goes through this provider unless you switch per send on the Email page. Rough guide by volume: Gmail for occasional notes (~500 recipients/day cap), SMTP2GO for regular club emails (free tier), Mailgun for larger volumes (paid, own domain).
Must be verified with SMTP2GO / Mailgun. Gmail always sends from the Gmail account itself.

The easy middle ground — a free account covers a typical club's announcements (currently 200 emails/day, 1,000/month free; see smtp2go.com/pricing). Works with any standard SMTP provider, not just SMTP2GO.

What you need:
  1. A free account at smtp2go.com.
  2. A verified sender: add the club's email address (or a domain you own) under Sending → Verified Senders and click the confirmation email — put that address in From address above.
  3. An SMTP user: Sending → SMTP Users → Add SMTP User — copy its username and password into the fields below.
Leave the password blank to keep the stored one.

For larger volumes — paid after the trial (see mailgun.com/pricing). The most setup of the three: it sends from a domain the club owns, not a plain email address.

What you need:
  1. An account at mailgun.com.
  2. A sending domain the club owns (e.g. mg.yourclub.org): add it under Send → Domains and create the DNS records Mailgun lists at your domain host — it shows "verified" when they're right.
  3. Your private API key from the Mailgun dashboard (API Security → API keys), and the region (US or EU) you chose when creating the domain.
Leave the API key blank to keep the stored one.

Gmail {% if email_provider == 'gmail' %}default{% endif %} {% if gmail_password_set and gmail_username %}configured{% endif %}

The simplest start if the club already has a Gmail address — no domain needed, but capped at roughly 500 recipients/day and emails always come from that Gmail address.

What you need:
  1. A Google account for the club (mail.google.com).
  2. 2-Step Verification turned on for it (myaccount.google.com/security).
  3. An App Password — not the normal password — created at myaccount.google.com/apppasswords (16 characters, shown once).
Leave it blank to keep the stored one.
