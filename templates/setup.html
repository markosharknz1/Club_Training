This one-time setup gets everything ready. It will:

Everything stays on this computer — no cloud, no accounts. See SECURITY.md in the app folder for the full story.

Not your Documents folder or anywhere OneDrive syncs — sync services corrupt the app's live database. (Daily backups still go to Documents automatically.) Installing over an earlier Club Training install keeps that club's data.
